# Methods

## Experimental Design & Data Source
The dataset consists of 12 biological replicates of *Saccharomyces cerevisiae* (BY4741 background), comprising 6 wild-type (WT) and 6 *snf2Δ* knockout samples. Raw data was obtained from the European Nucleotide Archive (ENA) under accession **PRJEB5348** (originally generated by Gierliński *et al.*, 2015). Sequencing was performed on an Illumina HiSeq 2000, yielding 51 bp single-end reads.

## Quality Control & Pre-processing
Raw sequence quality was assessed using [FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/). Adapter sequences and low-quality bases were removed using [Trim Galore](https://github.com/FelixKrueger/TrimGalore), which internally utilizes Cutadapt.

## Alignment & Quantification
Trimmed reads were aligned to the *S. cerevisiae* reference genome (Ensembl R64-1-1, release-114) using the [STAR](https://github.com/alexdobin/STAR) aligner (splice-aware). Gene-level read counts were quantified simultaneously during alignment using STAR's `--quantMode GeneCounts` parameter. The libraries were confirmed to be unstranded.

## Differential Expression Analysis
Statistical analysis of differential gene expression was performed in R using the [DESeq2](https://bioconductor.org/packages/release/bioc/html/DESeq2.html) package. 
* **Hypothesis Testing:** A Wald test was utilized to compare the *snf2Δ* condition against the WT baseline. 
* **Independent Filtering:** The False Discovery Rate (FDR) threshold was explicitly set to `alpha = 0.05` to optimize DESeq2's independent filtering, resulting in the exclusion of genes with a `baseMean` below 2.12. 
* **Effect Size Shrinkage:** To account for high variance in low-count transcripts, the resulting log2 fold changes were shrunken using the heavy-tailed `apeglm` prior estimator.

## Functional Enrichment
Differentially expressed genes were subjected to functional enrichment profiling:
* **Over-Representation Analysis (ORA):** Applied to the strictly filtered, significant gene set (padj < 0.05 & |log2FC| > 1) to identify significantly over-represented biological pathways.
* **Gene Set Enrichment Analysis (GSEA):** Applied to the full gene list, ranked by their shrunken log2 fold changes, to identify coordinated pathway shifts independent of strict significance cutoffs.

## Pipeline Architecture
The entire bioinformatics workflow was orchestrated using [Nextflow](https://www.nextflow.io/). All dependencies were packaged and executed within Docker containers to ensure end-to-end computational reproducibility. Final quality control metrics from all steps were aggregated into a unified report using [MultiQC](https://multiqc.info/).
